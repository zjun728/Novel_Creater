## 测试过程纠正与限制

- 首次停止脚本命中两个同名按钮，定位失败；任务随后完整生成 2355 字。这算第二次真实生成，不能算停止通过。
- 第二次停止发生在 0 字时，等待“需要重新审稿”的断言超时；实际状态符合无正文时不覆盖原稿。原异步等待方式未留下可核对的停止前数据，不能据此判断产品故障。
- 最终改为显式轮询真实 API 并记录停止前 DTO，取得 258 字 → 停止保留 256 字的完整证据。没有为了测试调整生产逻辑。
- 连接失败是隔离环境受控故障，不代表真实外部供应商事故；没有注入数据库断连、写回冲突、超时过期或进程崩溃。本批不能覆盖这些异常。旧稿保存失败、版本漂移等仍引用上一批有明确边界的单测 / 注入证据。
- 原型审稿结果完整弹窗、逐条忽略及其持久化尚未补齐；自动故事块 / 阶段 / 任务与跨卷承接仍待决，其他页面继续参照逐页复核清单。
