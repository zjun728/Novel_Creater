## 人工审阅准则

1. **辨识度**：同一标准场景下，十种风格是否在叙事距离、节奏、对白、情绪和信息释放上形成稳定差异，而不是只替换形容词。
2. **示例完整性**：标准场景与异情境应用示例是否都具备人物欲望、现实危机、选择、代价、对话潜台词和场景结果，能独立读懂。
3. **方法可用性**：经验卡 method 是否能直接指导一次写作选择；适用与不适用边界是否清楚；demo 是否真正演示该方法。
4. **类别覆盖**：十二类别是否满足旧八类各六张、新四类各四张，并且同类资产解决不同问题，不靠改写标题重复占位。
