# 写作样本分析报告

本报告只保留抽象写法方法，不包含小说原文长段。所有样本只可用于学习叙事方法，不可复刻人物、设定、原句和标志性表达。

## 合并标准候选：本地真人样本写作标准

- ID：local-human-sample-standard
- 分类：本地样本 / 待审核
- 来源样本数：46
- 禁止复刻：人物名、地名、势力名、专有名词、原句、连续表达、标志性比喻和独有段落结构

### 方法摘要

- 章节组织：章节进入：先把人物放进具体场景和可触摸的物件里，再让异常、冲突或信息缺口从动作中露出。；开章先给出人物正在做的事和身处的压力点，再用细节带出本章问题。；开章偏向用中长段铺出环境、处境和观察顺序，再转入人物选择。
- 对话方式：对话方式：对话承担关系张力和遮掩，允许停顿、转移话题和言外之意，不让角色主动替作者交代设定。；对话不必密集，但每次出现都要带身份、态度和未说出口的顾虑，避免纯信息问答。
- 人物方法：人物方法：人物应先按自身利益、恐惧、习惯和误判行动，再被主线牵动；关键反应尽量落在动作、停顿和物件互动里。
- 群像方法：群像方法：群像要给配角短期目的、顾虑或私心，让他们不只是递线索、送道具或解释规则。
- 任务/挑战：任务/挑战：任务/关卡应由选择代价、资源限制、误判后果和规则边界构成；胜负手要能从前文证据或行动中追溯。
- 情绪呈现：情绪呈现：情绪先通过迟疑、身体反应、习惯落空、无用细节和事后余波呈现，不急着写“他很痛苦/愤怒/绝望”。
- 信息释放：信息释放：信息从物件、证据、旁人反应、失败验证和关系变化中释放；避免老人、反派、系统或旁白一次性交底。
- 语言节奏：语言节奏：中长段承载观察、行动因果和心理余波，短句只用于转折、沉默和冲击点。；段落长短相对均衡，适合用中段推进场景，用短句留出停顿和余味。；短段落使用频繁，适合制造断裂和压迫；生成时需混入中长段承载观察、因果和情绪余波，让段落节奏有起伏，避免整章一短到底。
- 结尾倾向：结尾倾向：结尾落在关系变化、判断被推翻或新证据出现上，不用模板化内心总结。；结尾可短促收束，但要避免每章都变成动作加状态总结。；结尾适合落在一个具体物件、声音、痕迹或未解问题上，让读者带着证据感进入下一章。
- 避免项：不得复刻样本人物名、地名、势力名、专有名词和标志性意象；不得复制原句、连续表达和独有段落结构；减少套路化“不是X，是/而是Y”反差解释；避免动作后立刻替读者命名情绪；数字和术语必须影响风险、选择或后果；避免整章连续短句独段；必须禁止复刻原文、专有名词、人物名、地名、连续表达和标志性比喻
